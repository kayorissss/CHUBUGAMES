| Куда | Файл | Ссылка |
|---|---|---|

**Чем отличаются две версии для ПК?** Игра внутри одинаковая. `setup` ставится в систему как обычная программа
и умеет обновляться сам; `portable` ничего не устанавливает и запускается откуда угодно. Сохранения у них раздельные.
Если не уверен — бери `setup`.

Все сборки: [страница релизов](https://github.com/kayorissss/CHUBUGAMES/releases).

### Первый запуск на ПК: синее окно Windows

Windows покажет **«Система Windows защитила ваш компьютер»**. Нажми **«Подробнее» → «Выполнить в любом случае»**.

Это не признак вируса. SmartScreen считает репутацию по хешу конкретного файла, и у неподписанных программ
она **не переносится между версиями** — каждая новая сборка начинает с нуля. Поэтому предупреждение появляется
на каждом релизе, даже если предыдущий его уже перестал показывать.

Убрать это может только платный сертификат подписи разработчика, и то не мгновенно.
Проверить целостность файла можно по хешу SHA-256 — он публикуется в описании релиза.

Управление мышью. **Escape** — назад, **F11** — на весь экран. Работает полностью офлайн.
Прогресс с телефоном не синхронизируется — переносится файлом сохранения через настройки.

Оффлайн мобильное приложение с мини-играми про друзей.
Стиль — **Liquid Glass 2026**: жидкое стекло, чёрный / тёмно-серый / серый / белый + один акцентный цвет.

**Интернета не требует вообще.** Весь прогресс — в `localStorage`, вся графика рисуется на Canvas,

## Мета-игра («убить часы»)

- **CHUBCOINS** — единая валюта, **алмазы** — премиум-валюта
- **Уровни** (кривая XP), разблокировка игр по уровню
- **Перерождение (престиж)** — сброс ради очков навыков и **+12% монет** навсегда
- **Дерево навыков** — 9 узлов в 3 ветках (Жадность / Сила / Удача) с зависимостями
- **Сезон** — 30 тиров наград, мега-награды каждые 10
- **35 ачивок** четырёх редкостей
- **Ежедневный вход** — 7-дневная лесенка + стрик
- **3 задания в день** (детерминированы по дате)
- **Кейсы** с анимацией прокрутки и коллекция карточек друзей (+0.4% монет за карточку)
- **8 скинов героя** и **8 акцентных цветов**

## Сборка APK

APK собирается автоматически в GitHub Actions (`.github/workflows/build-apk.yml`)
через Capacitor при каждом пуше.

1. Открой вкладку **Actions** в репозитории
2. Возьми последний прогон *Build CHUBGAMES APK*
3. Скачай артефакт **CHUBGAMES-APK** → внутри `CHUBGAMES.apk`
4. Закинь на телефон и установи (нужно разрешить установку из неизвестных источников)

Воркфлоу фиксирует портретную ориентацию и **удаляет разрешение INTERNET** — приложение полностью автономно.

Либо запусти вручную: **Actions → Build CHUBGAMES APK → Run workflow**.
