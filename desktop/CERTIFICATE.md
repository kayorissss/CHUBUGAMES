# Подпись .exe: чем заполнить «Издателя» и убрать пугалку SmartScreen

> Вопросы, на которые этот файл отвечает:
> **«Пишет: Система Windows защитила ваш компьютер. Приложение: CHUBUGAMES-<версия>-portable.exe, Издатель: Неизвестный издатель. А можно издателя заполнить? Типа KAYORISAN или Chubu Inc.»**

## Короткий честный ответ

Поле «Издатель» в этом диалоге Windows берёт **не из свойств файла**, а из
**цифровой подписи Authenticode**. Подписи у нас нет — значит издатель будет
«Неизвестный» всегда, как бы красиво ни было написано `author.name` в
`package.json`. Написать там «KAYORISAN» или «Chubu Inc.» можно только одним
способом: купить сертификат у удостоверяющего центра, который подтвердил, что
KAYORISAN — это ты.

Что уже сделано в репозитории без сертификата:

| Что | Где | Что даёт |
|---|---|---|
| `CompanyName` / `ProductName` в свойствах exe | `package.json → author.name`, `desktop/builder.yml → copyright` | во вкладке «Подробно» и в UAC-диалоге установщика видно CHUBUGAMES / KAYORISAN |
| `nsis.publisherName: "KAYORISAN"` | `desktop/builder.yml` | «Издатель» в «Приложения и функции» Windows — метаданные установщика, реестр |
| Объяснение в описании релиза и в самом приложении | `build-desktop.yml` (`Prepare release notes`), игра перед запуском установщика | человек знает, почему Windows ругается, и сверяет SHA-256 |
| Место для подписи в CI | `build-desktop.yml → Prepare Authenticode certificate` | как только появятся секреты, оба `.exe` начнут подписываться **без правок кода** |

## Три рабочих пути (выбрать один)

### A. Azure Trusted Signing — самый дешёвый и самый правильный для инди

- **Цена:** ≈ 9,99 $/мес (подписка на Azure, платится только пока подписываешь).
- **Что нужно:** аккаунт Azure ≥ 30 дней, подтверждённый домен почты издателя
  (например `kayorisan.dev`, почта на нём), проверка организации по данным
  юрлиц/ИП. Для физического лица тоже есть ветка проверки.
- **Результат:** настоящая подпись «KAYORISAN», SmartScreen перестаёт пугать
  быстрее, чем с обычным OV-сертификатом (репутация строится по числу
  скачиваний, но сама подпись сразу «известный издатель»).
- **Как включить:** `az code-signing account ...` + `electron-builder` ≥ 26 с
  `win.azureTrustedSigning` (там же `tenantId` / `clientId` / `clientSecret` /
  `certificateProfileName`). Для нашей текущей версии (25.1.8) проще всего
  оставить как есть: у CI уже есть ветка с `CSC_LINK`, а при переходе на 26
  добавится блок `azureTrustedSigning` в `builder.yml`.

### B. OV / EV сертификат кода (DigiCert, GlobalSign, SSL.com, Sectigo, Certum)

- **Цена:** 100–400 $/год за OV; EV (или «OV + hardware token → облачный ключ»)
  дороже, но SmartScreen доверяет такому файлу **сразу**, без «накопления репутации».
- **Что нужно:** подтверждение личности/организации (для ИП/ООО — документы,
  для физлица — не все ЦС берут), выдаётся на 1–3 года.
- **Как подключить к нашему CI (это уже готово):**
  1. получить `.pfx` (экспортировать с паролем);
  2. `base64 -w0 chubgames.pfx` → одно поле;
  3. в репозитории создать два секрета: `WIN_CERT_PFX_B64` (эта строка) и
     `WIN_CERT_PASSWORD` (пароль от контейнера);
  4. следующий же релиз соберётся подписанным: шаг `Prepare Authenticode
     certificate` положит `CSC_LINK`/`CSC_KEY_PASSWORD`, и electron-builder
     подпишет и `portable.exe`, и `setup.exe`.
- Сам `.pfx` в git класть нельзя (репозиторий публичный) — ровно как и ключ
  Android из `android-signing/`.

### C. Microsoft Store (можно бесплатно)

Пакет подписывает Microsoft: SmartScreen не ругается никогда, «Издатель» —
твоя строка из аккаунта разработчика. Регистрация разработчика бесплатна для
бесплатных приложений (для платных и для IAP — 19 $ разово за верификацию
юрлица/физлица). Нужен `.appx`/MSIX вместо `portable.exe`, то есть отдельная
ветка сборки; `.exe` при этом тоже можно продавать рядом. Самый надёжный
«бесплатный» способ убрать предупреждение, но самый долгий по бумагам.

## Чего делать НЕ стоит

- **Самозваный сертификат (self-signed).** Работает ровно на тех машинах, где
  ты вручную положил его в «Доверенные корневые». Для всех остальных — та же
  пугалка, только с красным «имя не проверено». Подходит, чтобы проверить
  механизм подписи в CI перед покупкой:
  ```powershell
  New-SelfSignedCertificate -Type CodeSigningCert -Subject "CN=KAYORISAN" `
    -CertStoreLocation Cert:\CurrentUser\My
  # экспорт с паролем → .pfx → base64 → в секреты WIN_CERT_PFX_B64
  ```
- **Подпись «одолженным» или купленным с рук ключом.** Так банят аккаунты ЦС, и
  Windows начинает ругаться сильнее, чем без подписи.
- **Менять `author.name` в надежде, что «Издатель» появится.** Не появится
  (см. таблицу выше: меняются только свойства файла и реестр).

## Что говорить игроку, пока подписи нет

1. Предупреждение выглядит страшно, но это **не вирус**: Windows говорит, что
   файл не подписан и скачан из интернета («Additional properties» →
   Unblock).
2. «Подробнее» → «Выполнить в любом случае» — разовое действие на файл;
   после установки игра запускается без вопросов.
3. Файл можно проверить руками: SHA-256 лежит в релизе
   (`checksums.sha256`), а игра сверяет его сама перед запуском установщика.
4. Репутация SmartScreen считается **по хешу файла** и не наследуется между
   версиями: каждый новый релиз первое время снова показывает предупреждение,
   пока его не начнут качать.
